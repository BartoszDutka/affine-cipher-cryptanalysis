# Affine Cipher Cryptanalysis

A Python project exploring classical affine cipher encryption and analysis.

## Features

- Modular arithmetic and inverse operations
- encryption and decryption
- letter frequency analysis and candidate scoring
- ciphertext histogram visualization

## Technology stack

Python 3.8 or newer, optional matplotlib.

## Getting started

Review `affine_cipher_analysis.py` and `student_encryptor.py`. Install matplotlib if graphical output is desired. Run `python affine_cipher_analysis.py` from the repository directory. The affine cipher is a historical technique and is unsuitable for modern data protection.
